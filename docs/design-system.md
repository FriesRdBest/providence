# Design System

Providence uses a three layer visual language.

Primitive values define the base palette, spacing scale, corner radius, and focus colour. Toggl Red is #E05A47. Deep Charcoal is #2C2C2C. High Elevation Ivory is #FDFBF7.

Semantic roles express intent. They describe page backgrounds, surface backgrounds, primary text, secondary text, primary actions, and focus boundaries.

Component decisions use semantic roles rather than direct palette values. This keeps the interface consistent and makes future changes safer.

All interactive controls display a visible keyboard focus boundary. Text uses strong contrast against its surface. The interface remains readable at narrow and wide viewport sizes.
