# Ninety Day Operating Plan

The first thirty days establish trust in the data model, visual language, and core management views. The focus is reliable ingestion, understandable project health signals, and accessible navigation.

Days thirty one through sixty deepen the operational experience. The application adds filtering, richer project and people detail, quality checks, and a guided intelligence container for manager questions.

Days sixty one through ninety focus on adoption and resilience. The work includes stakeholder feedback sessions, performance review, security review, documentation refinement, and prioritised improvements based on observed use.

Each stage produces a working public application. Decisions are documented as they are made so that future contributors can understand the reason for each trade off.
